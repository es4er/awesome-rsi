# 递归自我改进智能体：研究阅读路线图

一个按原始资料 1:1 呈现的静态网页项目，整理了递归自我改进（RSI）、自进化智能体、训练、数据、评测与自动化 AI 研发等方向的 102 项代表资料。

## 在线部署

项目已包含 GitHub Pages 工作流。推送到 GitHub 后，在仓库的 **Settings → Pages** 中将 Source 设为 **GitHub Actions**，即可通过仓库的 Pages 地址访问。

## 本地预览

直接用浏览器打开 `index.html`，或在项目目录运行：

```bash
npx serve .
```

## 项目结构

```text
.
├── index.html
├── assets/
│   └── pages/       # 13 张原始页面
└── .github/
    └── workflows/
        └── pages.yml
```

## 说明

- 页面在 1440px 宽度下按原图尺寸呈现，并适配窄屏设备。
- 内容仅供学习交流与信息参考，论文结论请以原始文献为准。
- 原始资料中的分类与解读不代表相关作者或机构立场。
